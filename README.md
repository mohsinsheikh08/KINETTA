# 🏋️ KINETTA

Premium gym wear e-commerce platform with multi-CDN media architecture.

## 🛠️ Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB
- **Media:** ImageKit + Cloudinary (with failover)
- **Auth:** JWT
- **Real-time:** Socket.io

## ✨ Features

- Product browsing with filters
- Cart & Checkout (COD)
- JWT authentication
- Multi-CDN media pipeline
- Role-based admin
- Real-time chat

## 🚀 Quick Start

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
